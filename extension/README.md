# 🧩 إضافة المتصفح — مستخرج أرقام القضايا والتواريخ

نسخة الأداة كإضافة لمتصفح **Google Chrome** و **Microsoft Edge** (Manifest V3).

---

## ✨ ما الذي تضيفه على نسخة الويب

| الميزة | الوصف |
| --- | --- |
| زر في شريط الأدوات | الأداة متاحة في أي وقت دون فتح موقع |
| استخراج من الصفحة الحالية | يقرأ النص المحدَّد، أو نص الصفحة كاملاً إن لم يوجد تحديد |
| حفظ آخر نتيجة | تبقى النتائج عند إغلاق النافذة وإعادة فتحها |
| اختصار لوحة المفاتيح | `Ctrl+Shift+Y` (على macOS: `Command+Shift+Y`) |
| إزالة التكرار | تُحذف الأرقام والتواريخ المكررة مع الحفاظ على الترتيب |

الصيغ المستخرَجة هي نفسها: رقم القضية 10 أرقام متصلة، وتاريخ الإحالة `يوم/شهر/سنة`.

---

## 📥 التثبيت في Chrome

1. نزّل المستودع أو انسخه: `git clone https://github.com/abosalehg-ui/case-extractor.git`
2. افتح `chrome://extensions`
3. فعّل **وضع المطوّر** (Developer mode) من أعلى اليمين
4. اضغط **تحميل غير مضغوطة** (Load unpacked)
5. اختر مجلد `extension` داخل المستودع
6. ثبّت الأيقونة في شريط الأدوات من زر القطعة 🧩

## 📥 التثبيت في Edge

1. افتح `edge://extensions`
2. فعّل **وضع المطوّر** (Developer mode) من الشريط الجانبي
3. اضغط **تحميل غير مضغوطة** (Load unpacked)
4. اختر مجلد `extension`

> Edge يعتمد نفس محرك Chromium، فالإضافة تعمل فيه بلا أي تعديل.

## 🚀 طريقة الاستخدام

- **من صفحة ويب:** حدّد النص (أو اتركه بلا تحديد لقراءة الصفحة كاملة) ← اضغط أيقونة الإضافة ← **استخراج من الصفحة الحالية**
- **بلصق النص:** اضغط الأيقونة ← الصق النص ← الاستخراج يعمل تلقائياً عند اللصق
- انسخ كل حقل بزر **📋 نسخ** ثم الصقه في Word أو Excel

## 🔐 الأذونات ولماذا نحتاجها

| الإذن | السبب |
| --- | --- |
| `activeTab` | قراءة نص التبويب الحالي فقط، وفقط بعد ضغطك على أيقونة الإضافة |
| `scripting` | تنفيذ دالة قراءة النص داخل الصفحة |
| `storage` | حفظ آخر نتيجة محلياً على جهازك |

الإضافة **لا تتصل بالإنترنت ولا ترسل أي بيانات**، ولا تطلب صلاحية دائمة على المواقع. المعالجة تتم بالكامل داخل المتصفح.

صفحات النظام (`chrome://`, `edge://`, متجر الإضافات، وملفات PDF المدمجة) لا تسمح للإضافات بقراءتها — في هذه الحالة الصق النص يدوياً.
